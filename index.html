0clip - Privacy Policy

Last updated: 2 October 2026. Contact: hillelcohen07@gmail.com

What 0clip is

0clip is a personal, local tool that turns long videos into short vertical clips (cutting, cropping, subtitles, titles) and publishes them to the owner's own YouTube channel. It runs on a single computer, has a single user (its developer and owner), is not distributed, not sold and not hosted online. There is no account system and no third-party user data.

YouTube API Services

0clip uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using 0clip, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed through YouTube API Services, and why

  • Google sign-in (OAuth 2.0) with the scopes youtube.upload, youtube.readonly and yt-analytics.readonly: to upload the user's own videos, to display the name of the connected channel, and to read the statistics of the user's own channel.
  • Video upload and metadata (title, description, tags, category, language, privacy status, scheduled publish time, thumbnail): sent to YouTube on the user's explicit request, for the user's own channel only.
  • Public search (search.list, videos.list, channels.list): to display public videos matching the user's search (title, channel, thumbnail, view count, publish date, duration, declared language, subscriber count). Results are displayed as returned by the API, without modification, scoring or derived metrics, and each result links to YouTube.
  • Channel statistics (YouTube Analytics API, reports.query): official metrics of the user's own published videos (views, watch time, average view duration and percentage, likes, comments, shares, subscribers gained), displayed as returned.

0clip does not download, store or cache YouTube audiovisual content. It only processes video files that the user owns and provides (local files, or files from the user's own cloud storage).

Storage and security

  • All data stays on the user's computer, in a local data/ folder. Nothing is sent to a server operated by 0clip (there is none).
  • The OAuth refresh token is stored encrypted (AES-256-GCM) with a key kept outside the data folder. Access tokens are kept in memory only. Tokens are never written to logs.
  • Transport to Google uses HTTPS only.

Retention

  • Authorization tokens: kept as long as the user stays connected; deleted on disconnection (the token is also revoked with Google).
  • Public search results and "spotted" videos (video ID, title, channel, thumbnail URL, view count, publish date, duration): refreshed from the API or deleted after 30 days at the latest. The user's own free-text notes are not YouTube data.
  • Upload metadata and video IDs of the user's own published videos: kept with the local project as the user's own records.
  • Channel statistics (Analytics data): may be kept locally; they are re-read from the API on each visit and are only shown while the user's authorization is valid.

Sharing with third parties

To choose the best moments and write titles, descriptions and hashtags, 0clip sends the transcription of the user's own video and the user's own clip metadata to Anthropic (Claude), under Anthropic's terms. 0clip does not send YouTube API data (search results, other channels' data, channel statistics) to Anthropic or to any other third party. No cookies and no analytics or advertising services are used.

Revocation and deletion

  • The user can disconnect YouTube from 0clip at any time ("Disconnect" in the header): the token is revoked and deleted.
  • Access can also be revoked from the Google account security settings: https://myaccount.google.com/connections. 0clip deletes stored authorized data within 7 days of a revocation.
  • Any locally stored data can be deleted by deleting the data/ folder.

0clip - Politique de confidentialite

Derniere mise a jour : 2 octobre 2026. Contact : hillelcohen07@gmail.com

Ce qu'est 0clip

0clip est un outil personnel et local qui transforme des videos longues en clips verticaux courts (decoupe, recadrage, sous-titres, titres) et les publie sur la chaine YouTube de son proprietaire. Il tourne sur un seul ordinateur, a un seul utilisateur (son developpeur et proprietaire), n'est ni distribue, ni vendu, ni heberge en ligne. Il n'y a pas de comptes ni de donnees d'utilisateurs tiers.

YouTube API Services

0clip utilise les YouTube API Services (YouTube Data API v3 et YouTube Analytics API). En utilisant 0clip, l'utilisateur accepte d'etre lie par les Conditions d'utilisation de YouTube. Le traitement des donnees par Google est decrit dans les Regles de confidentialite de Google.

Donnees lues via les YouTube API Services, et pourquoi

  • Connexion Google (OAuth 2.0) avec les acces youtube.upload, youtube.readonly et yt-analytics.readonly : envoyer les propres videos de l'utilisateur, afficher le nom de la chaine connectee, lire les statistiques de sa propre chaine.
  • Envoi de videos et metadonnees (titre, description, tags, categorie, langue, visibilite, date de publication programmee, miniature) : envoyes a YouTube a la demande explicite de l'utilisateur, sur sa seule chaine.
  • Recherche publique (search.list, videos.list, channels.list) : afficher les videos publiques correspondant a la recherche de l'utilisateur (titre, chaine, miniature, vues, date, duree, langue declaree, abonnes). Les resultats sont affiches tels que renvoyes par l'API, sans modification, sans score ni donnee derivee, et chaque resultat renvoie vers YouTube.
  • Statistiques de la chaine (YouTube Analytics API, reports.query) : metriques officielles des propres videos publiees de l'utilisateur (vues, minutes vues, duree et pourcentage moyens de visionnage, j'aime, commentaires, partages, abonnes gagnes), affichees telles quelles.

0clip ne telecharge, ne stocke et ne met en cache aucun contenu audiovisuel YouTube. Il ne traite que des fichiers video qui appartiennent a l'utilisateur et qu'il fournit lui-meme (fichiers locaux ou issus de son propre stockage en ligne).

Stockage et securite

  • Toutes les donnees restent sur l'ordinateur de l'utilisateur, dans un dossier local data/. Rien n'est envoye a un serveur exploite par 0clip (il n'y en a pas).
  • Le jeton de rafraichissement OAuth est stocke chiffre (AES-256-GCM) avec une cle conservee hors du dossier de donnees. Les jetons d'acces restent en memoire. Aucun jeton n'est ecrit dans les journaux.
  • Les echanges avec Google se font uniquement en HTTPS.

Durees de conservation

  • Jetons d'autorisation : conserves tant que l'utilisateur reste connecte ; supprimes a la deconnexion (le jeton est aussi revoque aupres de Google).
  • Resultats de recherche publique et videos « reperees » (identifiant, titre, chaine, URL de miniature, vues, date, duree) : rafraichis depuis l'API ou supprimes au plus tard apres 30 jours. Les notes libres de l'utilisateur ne sont pas des donnees YouTube.
  • Metadonnees d'envoi et identifiants des propres videos publiees de l'utilisateur : conserves avec le projet local, comme ses propres archives.
  • Statistiques de la chaine (donnees Analytics) : peuvent etre conservees localement ; elles sont relues depuis l'API a chaque visite et affichees seulement tant que l'autorisation de l'utilisateur est valide.

Partage avec des tiers

Pour choisir les meilleurs moments et ecrire titres, descriptions et hashtags, 0clip envoie la transcription de la propre video de l'utilisateur et ses propres metadonnees de clips a Anthropic (Claude), selon les conditions d'Anthropic. 0clip n'envoie aucune donnee des YouTube API Services (resultats de recherche, donnees d'autres chaines, statistiques de chaine) a Anthropic ni a aucun autre tiers. Aucun cookie, aucun service de mesure d'audience ou de publicite.

Revocation et suppression

  • L'utilisateur peut deconnecter YouTube de 0clip a tout moment (« Deconnecter » dans l'en-tete) : le jeton est revoque et supprime.
  • L'acces peut aussi etre retire depuis les parametres de securite du compte Google : https://myaccount.google.com/connections. 0clip supprime les donnees autorisees stockees dans les 7 jours suivant une revocation.
  • Toute donnee stockee localement peut etre supprimee en effacant le dossier data/.
